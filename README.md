# Vita Nova Perfumería
Para cambiar el catálogo edita SOLO `catalogo.js` (activar/ocultar con `activo`, agotar con `enStock`, precios, fotos).
Fotos: sube la imagen a `img/` y pon `fotos: ["img/nombre.jpg"]` en ese perfume.
Despliegue: al subir los cambios a GitHub, Netlify actualiza la página solo.
